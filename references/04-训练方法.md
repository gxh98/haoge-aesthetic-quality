# 训练方法

> 何时读我：路径 C（练）必读。
> 来源：贾行家《人文课堂》100《AI 时代的美学训练》+ 099《像创造者一样审美》（原文）。

## 一、为什么需要训练

**AI 时代独特质感的训练方法，来自人的观察力、意图、结构，以及实践中的控制和选择能力。**

贾行家的判断：
- AI 大量缩减了设计岗位，但不代表设计师就更好招
- **真正的变化是能力结构变了**——从"闷头画画的艺术生"变成"擅长沟通的项目经理"
- 核心能力：**能听清需求、能生成调试、能把结果推销出去**

**素描这样的基础训练，实际上是在训练人"看东西"的能力。**

你天天见面的熟人，你以为自己很了解他，但是只要你尝试给他画一幅像，就会发现，他的脸上还是有那么多你从前没有注意到的细节。

## 二、观察力训练

### 训练 1：一次只改一个参数

**方法**：
1. 生成两张图（或两版文案/两版网页），只改一个变量（比如只改背景色）
2. 对比看差异——哪个更好？为什么？
3. 确认后再改下一个参数

**目的**：训练"辨认力"——能准确地描述比例、色彩、光影以及空间关系。

**判断标准**：能说清"改了哪个参数、效果如何"=迭代有效；一次改了好几个变量=不知道是哪个起的作用=白改。

### 训练 2：观察—行动—再观察

**方法**：
1. **观察**：先看一个作品，形成自己的判断
2. **行动**：做一版（或改一版）
3. **再观察**：看结果，对比之前的判断
4. 循环往复

**目的**：训练自己的判断和校正反应。

**案例**：中央音乐学院招生——
> 一位考生演唱完，在场者都觉得很好。评审老师说："这位同学，你声带大约多少厘米的位置，有一个小结节。你回去查一查吧。"回去做了个喉镜，位置和大小，和老师说的一样。

**观察力的准确、专业，和对材料的控制、选择水平，始终能正确处理的能力，是高度一致的。**

### 训练 3：抛开说明独立看

**方法**：
1. 看一幅画，**不用看策展文案**，自己先去观察
2. 看一部电影，**甭管豆瓣打几分**，就让自己去形成自己的感受
3. 之后，**可以让观看变成对照**：自己先有一个独立的描述，再去对照他人的评论，看看别人是用什么方式观察、形成的判断

**目的**：训练独立观察力，不被他人的诠释绑架。

**判断标准**：能否准确描述比例、色彩、光影、空间关系 = 观察力到位。

### 训练 4：描述练习

**方法**：看完一个作品，用一句话准确描述"它好在哪"。

**禁止**：只说"好看""高级""有感觉"。
**必须**：说清"比例/色彩/光影/空间关系"。

**参考**：内行评价质感的问题，会明确地指出细节——"这里的比例不对，造成主次不分""这个面应该是连续的，不应该有接缝"——也会给出具体的解决办法。

**外行**觉得不对劲会说"就是看着有哪里不顺眼""就是有一种廉价感"——感觉是有理由的，但因为缺少经验，描述不清楚，提出来的改进方向也很可能不靠谱。

## 三、浸泡与回避

### 浸泡熏陶

**主动收集美**：好网站、好设计、好产品、好图片，建自己的"美感样本库"。

**案例**：高古奇喜欢收集美——世界各地的椅子，甚至 19 世纪的一只金属假肢。

### 回避污染

**不允许自己的生活里出现"不美"的东西**：
- 删掉丑的 App
- 取关低质账号
- 换掉丑的日用品

**案例**：高古奇不允许自己的生活里出现不美的日用品。

### 不可逆性

**美真正奢侈的地方**：当你在某个领域里体验过了美和高品质，形成了体感，就回不去了，就没法再容忍低劣的、粗心大意的、应付了事的东西。

**这就会让你为之投入得越来越多。** 高品质从来就不容易实现和遇到，却很容易在随意和妥协里滑坡。

**案例**：回忆一下你们家乡最引以为豪的名吃，再想想它在外地、在火车站和仿古步行街里被糟改到什么程度——就知道那种生理不适，以及愤怒的情绪。

## 四、迭代法（一次只改一个参数）

**方法**：
1. 当前版本保存为 V1
2. 只改一个参数（比如只改标题字号），生成 V2
3. 对比 V1 和 V2——哪个更好？为什么？
4. 确认后再改下一个参数

**判断标准**：能说清"改了哪个参数、效果如何"=迭代有效。

**常见误用**：一次改一堆——"我把颜色、字体、布局都改了"=不知道是哪个起的作用。

## 五、训练计划模板

```
【当前水平】
- 能否准确描述比例/色彩/光影/空间关系？
- 能否独立判断一个作品的质感等级？
- 能否说出"为什么好/为什么差"？

【本周训练】
- 浸泡：收集 3 个"有质感"的作品，写清"好在哪"
- 回避：删掉 1 个"不美"的东西
- 练习：一次只改一个参数，做 3 组对比
- 描述：看完一个作品，用一句话准确描述"它好在哪"

【下周检验】
- 能否更快地看穿"粗劣"？
- 能否更准确地描述"好在哪"？
```

## 六、训练时的检查清单

- [ ] 一次只改一个参数，没有一次改一堆
- [ ] 观察—行动—再观察，循环往复
- [ ] 抛开说明独立看，没有被他人的诠释绑架
- [ ] 描述具体，没有"好看/不好看"
- [ ] 浸泡了美，也回避了污染
