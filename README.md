# 昊哥-审美质感（haoge-aesthetic-quality）

> 把「我觉得好」变成「我知道它为什么好、怎么做到的、我怎么复刻」。

## 为什么有它

问 AI「这个设计怎么样」，它给你两句「很有质感」「布局清晰」，然后没了。

问题不在 AI 不会夸人，在**没人告诉它审美是可以拆的**：

| 判断质感真正需要 | 大多「审美点评」的做法 |
|---|---|
| 先看清这件东西是想干什么 | 上来就评好不好看 |
| 分三层看：材料真不真、处理到不到、预期符不符 | 一句「高级感」概括 |
| 说清「好在哪」要指到具体位置 | 只给形容词 |
| 承认粗粝也可能是好的，粗劣一定是坏的 | 把「不精致」一律判死 |
| 落到「我怎么做出同水准的东西」 | 停在评价 |

这个技能把贾行家《人文课堂》质感三讲的方法完整搬进来，并且**强制每个判断都要给依据**——这是整套方法最硬的一条纪律，也是绝大多数审美点评烂掉的地方。

## 三层闭环：拆 / 用 / 练

| 层 | 你给它什么 | 它给你什么 |
|---|---|---|
| **拆** | 一张图、一个网站、一篇图文、一段文案、一个技能、一家门店 | 五维扫描 + 好在哪 + 结构分析 + 改进方向 |
| **用** | 一个想达到的水准 + 你要做的东西 | 意图卡 + 导演式提示词 + 控制力检查 |
| **练** | 你想提升的眼力 | 观察力训练 + 浸泡清单 + 迭代计划 |

三层的顺序不能倒：**先会拆，才谈得上用；用得多了，眼力才是自己的**。

## 十三种用法

**拆（5 类）**：图片 / 网站与网页 / 技能 / 图文与文案 / 门店形象

**用（5 类）**：做图 / 做网页与主页 / 做产品详情页 / 做网站 / 做抖音图文

**练（3 类）**：AI 提示词质感评审 / 日常观察力训练 / 招聘与外包的审美尽调

不确定走哪条？直接说你要干什么，技能会自己路由。

## 一条铁律：每个判断都要指到具体位置

「这个图有质感」是废话。

「这个图有质感，因为它的阴影方向只有一束主光、没有补光，所以物体看起来是**被放在一个真实房间里**，而不是被抠出来贴在背景上」——这是判断。

课程里所有拆解示范都在做同一件事：**把「好看」拆成可以复述、可以复制、可以被别人检验的具体动作**。所以这个技能不允许输出只有形容词的评价。

## 一个真例子

拿归藏的设计插件当拆解对象跑一遍路径 A：

**整体判断**：有质感——因为它用「限制自由发挥」实现了「稳定输出」。

**好在哪**（五维扫描）：
- **材料诚实**：归藏不假装 AI 能一次做对设计，把「AI 会犯错」这件事直接写进流程
- **结构优先**：先立设计系统（Design Token），再定设计规则，最后上自查机制——三层，不是一堆提示词
- **限制即品质**：Design Token 只能选不能编，这跟安藤忠雄用清水混凝土限制工人手艺是同一个思路
- **改进方向**：还可以更进一步考虑「对人的照顾」——规则是给 AI 的，但最终看的人是老板，规则里没有一句话在替看的人着想

完整拆解过程见 `建造档案.md`，方法可复现。
